The MyList class
================

Import module:
    >>> MyList = __import__('1-my_list').MyList

Create a list:
    >>> my_list = MyList()

Check types:
    >>> type(my_list)
    <class '1-my_list.MyList'>

Append elements:
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)

Print original list:
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Print sorted list (should print sorted but keep original order):
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

Verify original list is still unsorted:
    >>> print(my_list)
    [1, 4, 2, 3, 5]
